# CRUD-Basico
Um CRUD simples para eu aprender e me familiarizar com o padrão CRUD.

Tecnologias Usadas:

Python,
Flask,
SQL,
html,
Jinja2

Funcionalidades:

Cadastrar usuários,
Listar usuários,
Editar usuários,
Deletar usuários

Como rodar o projeto:

git clone https://github.com/davinasct4044/CRUD-Basico.git,
pip install Flask,
python app.py

obs: Tem q ter o python instalado.
